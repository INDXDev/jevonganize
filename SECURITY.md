# Security policy

Please do not report vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/INDXDev/jevonganize/security/advisories/new) on
this repository.

We especially want to hear about ways a file's name, contents or metadata could:

- Expose API keys
- Run commands on a user's machine
- Write outside the folders a user chose
- Reach the local server

The [threat model](docs/security.md#threat-model) says what is in scope.

Only the latest release receives security fixes.
